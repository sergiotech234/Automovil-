# Ejercicio: Clase Automovil

## 📌 Descripción

Este ejercicio consiste en desarrollar una clase llamada `Automovil` utilizando los conceptos de **Programación Orientada a Objetos (POO)** en Java.

La clase representa un automóvil y almacena su marca, modelo y año de fabricación. Además, incorpora una constante estática para establecer el año del primer automóvil y utilizarlo como referencia en las validaciones.

## ⚙️ Validaciones

Se establecen las siguientes condiciones:

- La marca no puede estar vacía.
- El modelo no puede estar vacío.
- El año no puede ser inferior a `1886`.
- Se acepta el año `1886` y cualquier año posterior.

Si se intenta introducir un valor que no cumple estas condiciones, debe rechazarse mediante una validación.

## ✅ Conclusión

Con este ejercicio se refuerzan los conocimientos de programación orientada a objetos en Java, especialmente el uso de atributos privados, constructores y métodos de acceso.

Además, se aprende a utilizar constantes mediante `public static final`, comprendiendo que pueden consultarse directamente desde la clase sin necesidad de crear objetos.

Por último, se practican las validaciones de datos para garantizar que los automóviles tengan información correcta y que su año de fabricación no sea anterior a 1886.
